An open-source trading bot for Polymarket's Bitcoin 15-minute markets

A Python bot that watches every BTC Up/Down window and buys the favorite side, UP or DOWN, only inside a tight price band. Every trade has a take-profit and a stop-loss, and the bot halts itself on daily-loss and drawdown limits. It comes with a local dashboard to watch and control it.

How it works

A favorite strategy on Polymarket's “Bitcoin Up or Down – 15 minutes” markets.

  1. 1

    Scan

    Every few seconds the bot finds the live 15-minute BTC window and reads the CLOB order book and a BTC spot feed.

  2. 2

    Filter

    It enters only if one side, UP or DOWN, is the favorite inside a set price band (for example 70–75¢), enough time is left, the spread is tight, and the expected edge still beats the taker fee.

  3. 3

    Size

    Each position is capped by a $ per-trade limit, a % of bankroll, and total exposure limits. If there isn't enough room, it skips.

  4. 4

    Exit

    It takes profit when the bid reaches the target (for example 97¢), stops out when the loss reaches the stop (for example −60%), or holds to resolution.

  5. 5

    Halt

    It stops for the day after a daily-loss limit, stops after a max drawdown from peak, and cools down after losses. A kill switch flattens everything.

Features

📊

Local dashboard

Live mode and status, bankroll, today's and total P&L, win rate, open positions marked at the live best bid, a cumulative P&L chart, trade history, a decision feed for every window, and the log. Start, stop and restart it in one click.

🧭

One-minute onboarding

On first run, a setup screen asks for your wallet, mode and starter limits. The key is written only to the local .env file, never shown again, never logged, and wallet changes are accepted only from 127.0.0.1.

🛡️

Hard risk limits

Per-trade $ cap, max trades per day, max open positions, a daily-loss halt, a max-drawdown halt, a consecutive-loss limit with cooldown, and an exposure cap. Each one is editable in Settings.

🧪

Paper mode first

Paper is the default: it simulates fills against the real order book and places no orders. Going live means typing GO LIVE and ticking a real-money confirmation.

🧾

Honest bookkeeping

Fees are included in the cost basis. The bankroll is cash + open positions + unredeemed winners. Each decision and fill is written to CSV, and state persists across restarts.

🔁

Backtest tools

collect_data.py and backtest.py replay the bot's own rules on market history, so you can test settings before risking anything.

Quick start (~2 minutes)

You need Python 3.11+ (on Windows, tick “Add python.exe to PATH”) and git.

1

Clone

git clone https://github.com/SammyCodes1/polymarket-btc-bot.git
cd polymarket-btc-bot
2

Launch the dashboard

On Windows, double-click start_dashboard.bat. On macOS/Linux, run:

./start_dashboard.sh

The first run creates .venv, installs the requirements and opens http://127.0.0.1:8787/.

3

Add your wallet locally

On the setup screen at 127.0.0.1, which runs on your own machine, enter your private key and Polymarket wallet address. Use a dedicated wallet that holds only money you can afford to lose. You can also skip this and explore in paper mode.

4

Choose Paper or Live

Paper is the default. Live requires typing GO LIVE and ticking “I understand this uses real money”.

5

Set limits and start

Set the starter limits, then click Save & Start. You land on the live overview.

Manual setup without the launcher 
# macOS / Linux
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # edit by hand, or use the dashboard setup screen
python bot.py               # runs forever; Ctrl+C to stop
python dashboard/server.py  # http://127.0.0.1:8787/

# Windows
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env

Never commit .env. It's already in .gitignore. The full docs are in the README.

⚠️ Read this before you use real money

  • This is real money, and there's no guarantee. It's experimental software, not financial advice. You can lose everything you put in.
  • Expected value can be negative. 15-minute BTC moves are close to random. These markets are priced by fast, well-informed traders. The taker fee (0.07 × p × (1−p) per share) and the bid/ask spread eat small edges. Loosening the thresholds generally makes results worse, not better.
  • Past and backtest results don't predict future returns. Paper-trade for days first. If you go live, use a small amount you can afford to lose.
  • Polymarket geoblocks some countries. Trading is blocked or close-only in places including the US, UK, France, Germany, Italy, Belgium, Poland, Australia, Brazil, Singapore, Taiwan, Thailand and others. Check Polymarket's current list and follow the rules where you live. Don't use a VPN to get around restrictions.
  • Your keys stay on your machine. Your private key belongs only in the local .env file on a computer or server you control. Never paste a private key into any website. That includes this page, chat apps, and anyone claiming to “help set up” the bot. Anyone with the key controls the wallet.

Read the code. Run it in paper mode. Decide for yourself.
